# Library API

This project is a simple library management API built using FastAPI.

## Features
- View books
- Borrow books
- Return books
- Check overdue books

## How to Run

1. Install dependencies:
   pip install fastapi uvicorn

2. Run the server:
   uvicorn main:app --reload

3. Open browser:
   http://127.0.0.1:8000/docs
